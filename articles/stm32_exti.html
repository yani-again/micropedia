STM32 EXTI (External Interrupts And Events Controller)

The standard interrupts that come with an STM32 can feel limiting; sometimes you want to turn a certain external event into an interrupt, that way you know when it happened without entering a blocking while loop and holding the entire CPU up.

Well, as luck would have it, that's exactly what the STM32 EXTI is for!

EXTI Overview

For the most part, the EXTI block can look at GPIO pin edges and generate an interrupt or event upon a change (you as the programmer can decide which edge to watch).

However, wake-up signals can also be used from other peripherals such as the RTC, UART, PVD...

Take a look at the block diagram below from the STM32G0, you can see how the EXTI block (gray area) sits between the peripheral which generates the event and the GPIO itself.

Figure 26 - EXTI block diagram

I've done enough hinting already, think of the EXTI as having 3 main purposes:

  1. Detecting GPIO signal edges
  2. Routing which GPIO port drives which EXTI line
  3. Waking up from low-power modes

**Note that this article is written using the Nucleo-STM32G031K8 as the main MCU and thus uses its reference manual[1]. Register names and some implementation details may vary across different STM32s.

EXTI Lines

Each EXTI line is an independent input, with there being 2 kinds of line:

  • configurable lines: GPIO-connected lines labelled EXTI0-15 (yes there are 16 of them)
  • direct lines: directly from peripheral wake-up sources (e.g. UART, I2C, RTC)

GPIO-Mapped Lines

Each GPIO port has a maximum of 16 pins, which is why the EXTI also has 16 GPIO-connected lines.

An EXTI line (e.g. EXTI4) maps to one GPIO port at the same number (for EXTI4, that can be any one of PA4, PB4, PC4...).

On the STM32G0, this is configured inside the EXTI_EXTICRx registers.

Relevant Registers

| Register | Purpose | | -------- | ------- | | EXTI_RTSRx | Enable trigger on rising edge detection | | EXTI_FTSRx | Enable trigger on falling edge detection | | EXTI_IMRx | Interrupt mask (setting 1 = interrupt can trigger) | | EXTI_EMRx | Event mask (setting 1 = event can trigger) | | EXTI_SWIERx | Software interrupt, fakes an edge to trigger interrupts | | EXTI_RPRx | Rising edge pending flags* | | EXTI_FPRx | Falling edge pending flags* | | EXTI_EXTICRx | GPIO port selection |

* These can be used in the ISR to figure out which line and edge triggered the interrupt. Don't forget to clear!
